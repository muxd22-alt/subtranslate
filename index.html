subtranslate offline

Offline English to Arabic subtitle translation on device.

Install

npm install -g subtranslate
npm install -g subtranslate
npm install -g subtranslate

Quick start

subtranslate examples/hello.en.srt "Hello"

Commands

CommandPurpose
subtranslateTranslate an English SRT to Arabic
subtrFind and translate a movie subtitle
subfindDownload a subtitle next to a video
subsync-enRe-time an English subtitle

Good trees

Movies/Movie (2010)/Movie (2010).en.srt -> Movie (2010).ar.tran.srt

Bad trees

Movies/Movie (2010)/Movie (2010).ar.sub.srt is a human track, never overwritten

Output

.en.srt becomes .ar.tran.srt. Untagged .srt becomes .ar.tran.srt. .eng.forced normalizes to one .ar.tran.srt. Exit code 4 = validator rejection; use --reject-out.

Troubleshooting

Model missing

Run subtranslate --fetch-model.

Validator rejection

Inspect with --reject-out.
