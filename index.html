subtranslate offline

Offline English → Arabic subtitle translation, on device. One model download, then no network at all.

What it does

It reads an English .srt, translates it to Arabic with a local Bergamot/Marian model, validates the result, and writes it next to the source as .ar.tran.srt. The machine track is kept separate from a human or downloaded Arabic track (.ar.sub.srt), so Jellyfin and Plex can show both without either overwriting the other.

Install

pkg install nodejs-lts git
git clone https://github.com/muxd22-alt/subtranslate.git
cd subtranslate
sh install.sh

install.sh installs the dependencies, downloads the en→ar model (~34 MB, once), links subtranslate and puts subfind, subsync-en and subtr into $PREFIX/bin.

The npm package ships the same model fetch; run subtranslate --fetch-model once after installing.

Quick start

# 1. fetch the model once (~34 MB). install.sh already did this.
subtranslate --fetch-model

# 2. translate a file
subtranslate examples/hello.en.srt "Hello"

# 3. the machine track is written next to the source
cat examples/hello.ar.tran.srt

After the model is on disk the tool never touches the network again.

subqwen: the second pass

The translator is a small model, so it gets the gender wrong, it transliterates names nobody recognises and it writes every film in the same flat voice. subqwen re-reads the result with the English source and a small local model, and fixes only what is really wrong.

subqwen refine Movie.2026.mkv
subqwen refine Movie.2026.mkv --dry-run
subqwen brief Movie.2026.mkv
subqwen doctor --live
  • Cue numbers, timings and line breaks never change. Only the text of a cue is rewritten, and only when the rewrite passes a mechanical gate.
  • The raw translation is kept at ~/.cache/subgrab/raw/<hash>.srt, so a refinement can always be undone.
  • Sound only cues are dropped: a professional subtitle has no stage directions in it.
  • The model gets a short brief about the film: title, genres, a tone line and the main characters with their gender. The gender comes from the metadata provider and is never guessed.
  • The brief comes from TMDB when there is a key, and from TVmaze or Cinemeta when there is not.

Folder layouts

Good movie tree

Movies/Movie (2010)/Movie (2010).en.srt
  -> Movies/Movie (2010)/Movie (2010).ar.tran.srt

Good TV tree

TV/Show/Season 1/Show.s01e01.en.srt
  -> TV/Show/Season 1/Show.s01e01.ar.tran.srt

Bad movie tree

Movies/Movie (2010)/Movie (2010).ar.sub.srt

A human (or downloaded) Arabic track. It is never overwritten: the translation goes to Movie (2010).ar.tran.srt next to it, and Jellyfin shows both tracks as Arabic.

Bad TV tree

TV/Show/Season 1/Show.s01e01.srt

Untagged, so the language is ambiguous: it still becomes Show.s01e01.ar.tran.srt, but the source is not obviously English and a sibling .en.srt is the clearer layout.

Output rules

  • .en.srt → .ar.tran.srt
  • untagged .srt → .ar.tran.srt
  • .eng.forced, .en.sdh, .english.srt normalise to one .ar.tran.srt
  • an explicit --out always wins
  • .ar.sub.srt is the human track, .ar.tran.srt is the machine translation — they never collide

Validation and exit codes

The translation is checked before the file is written: it must really be Arabic, must not be half translated, and must cover the source. A rejected run exits 4 and writes nothing.

CheckDefaultRejects
Arabic letter ratio0.88English passthrough
Arabic cue ratio0.90half-translated files
English-only cuesat most 0.10blocks of untouched English
source cue coverage0.85output missing many source cues

Keep a rejected translation for inspection with --reject-out <path>.

Performance

Translation runs on 4 worker threads in waves of 200 cues (--workers, --chunk). The model is ~34 MB on disk and runs fully offline, so this is the heaviest step on the device. See docs/model-parallelism.md.

Troubleshooting


Model missing
Run subtranslate --fetch-model.


Validator rejection (exit 4)
Inspect with --reject-out; the thresholds are listed above and measured in docs/validation.md.


Command not found after install
Make sure $PREFIX/bin is on PATH; on Termux that is usually export PATH="$PREFIX/bin:$PATH".
